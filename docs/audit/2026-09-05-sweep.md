### S2-1 · `scripts/real_fetch_check.py:195` · category C/H

```python
for error in exc.cause.errors(include_url=False):
```

`exc` is an `OutputValidationError`. That class (`core/validation.py:40-44`) sets `self.label`, `self.errors`
(a **tuple** of pairs) and `self.error_count`, and nothing else — `core/validation.py:76-78` raises it
`from None` precisely so the pydantic `ValidationError` is neither stored nor chained. There is no `.cause`
attribute, so this line raises `AttributeError`. The next line, `error["loc"]`, would also fail: `errors` is a
tuple of `(location, type)` pairs, not a list of dicts, and it is not callable.

**Why S2:** this is the branch that runs when the live backend's response shape does not match the confirmed
schema — the single outcome the script exists to detect, at the joint verification session (Step 0). Instead of
printing the field paths it would crash with an unrelated `AttributeError`. Nothing covers it: `scripts/` is
outside `--cov` and has no test.

**To fix:** read `exc.errors` (the tuple) and `exc.label` directly; drop `exc.cause` and the `error["msg"]`
access, which no longer exists by design. **Touches:** `scripts/real_fetch_check.py` only.

### S2-2 · `tests/unit/test_judgement_routes.py:434-442` · category G

```python
def test_a_failure_after_reserving_releases_the_key(client, leads, operational):
```

The inline comment concedes the shape ("drives the release through the counter path instead") without noticing
that the counter path cannot fail the request.

**Why S2:** `pipeline.py`'s own docstring calls this path "the difference between 'retry your request' and '409
for the next 24 hours'". A named test sits on it and exercises none of it. The real coverage lives in
`test_judgement_pipeline.py:170-216`, so the guarantee is not unprotected — but this test's name says the route
layer is covered, and it is not.

**To fix:** drive a failure that actually raises after the reservation (the `test_judgement_pipeline.py` tests
patch `token_preflight`), or rename to what it checks. **Touches:** one test.

### S2-4 · `tests/unit/test_tenant_label_properties.py:63-68` and `:73-75` · category G


1. **Does the 300-character clarification-prompt cap belong in `TenantConfig`?** `config.py`'s docstring claims
